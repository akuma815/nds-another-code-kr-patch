# Another Code NDS 한국어화 인수인계

작성/갱신일: 2026-08-23

## 현재 중단점

일본판 원본의 NDS 구조, 텍스트 모집단, 제어 토큰, 직접 포인터 참조와
`font_lc.bin`을 분석했습니다. Galmuri `한`은 melonDS 1.1의 실제 주 대화
렌더러에서 표시가 통과했습니다. `%v(006) なあに、アシュレイ`를 최초 대화로 본
가정은 사용자 런타임으로 폐기했습니다. 사용자가 제시한 실제 최초 자동 화면은
`１３才最後の朝 / 気分は最悪だった`이고, overlay 0의 정확한 레코드를 찾았습니다.
이를 `열셋마지막아침 / 기분은최악이었다`로 바꾼 인트로 PoC는 정적 빌드·diff·
11개 테스트를 통과했습니다. 초기 8×8 2배 확대는 글자가 뭉쳤지만, 사용자가 제공한
`Galmuri11-Condensed_16x16(12px).png`로 재빌드한 결과 melonDS에서 크기와 가독성이
좋다고 승인했습니다. 이 폰트를 프로젝트 확정 폰트로 고정했습니다. 사용자 런타임
스크린샷으로 기존 두 번째 번역 레코드가 실제 화면 3임을 확인했습니다. 일본어로 남은
화면 2는 `arm9_overlay_000_file_000:004034`이며, 포인터 표 뒤에 NUL 구분 없이 시작해
기존 추출에서 빠졌습니다. 정렬된 직접 포인터 표적 복구를 추가하고 첫 3화면 번역 SSOT와
50자 매핑을 빌드했습니다. 새 ROM은 정적 검증과 테스트를 통과했고, 사용자가
melonDS 스크린샷으로 세 화면 모두 정상 출력됨을 확인했습니다. 이후 화면 4부터 문장을
하나씩 찾는 방식 대신 전체 번역 파이프라인으로 전환했습니다. 현재 카탈로그와
검토 후보를 합친 2,789행 UTF-8 CSV를 생성했습니다. 사용자가 번역한
`another_code_full_text_v1_ko.csv`를 최종 번역 SSOT로 인계했으며 내용은 수정하지
않았습니다. 기준 CSV와 읽기 전용 대조한 결과 보호 열·행 순서·2,789개 ID와 모든
`%...` 토큰이 일치했습니다. accepted catalog 2,748행은 전부 채워졌고, 빈 36행은 모두
재삽입 금지 `isolated_candidate`입니다. 기존 슬롯과 0~3바이트 NUL 정렬 패딩만 묶는
재배치 모델로 36개 component 모두 용량 수용 가능함을 정적으로 확인했습니다. 이 모델을
Expected Write writer로 구현하고 최종 CSV의 첫 3화면을 사용한 새 PoC ROM을 만들었습니다.
overlay 0의 accepted 18개 레코드를 2개 확인 영역에 재패킹하고 18개 직접 포인터를 모두
갱신했으며, 정적 빌드·구조 diff를 통과했습니다. 사용자가 선택한 첫 3화면 모두 정상
출력을 확인해 길이 증가·NUL 경계·직접 포인터 재배치 게이트를 통과했습니다. 다만
3번째 뒤 화면으로의 진행은 이번 응답에 명시되지 않아 별도 증거로 남기지 않았습니다.
이어 4,375개 글리프 코드 전수 감사와 27개 테스트를 완료했습니다. 최종 824자 수요에
대해 알려진 CSV 원문 모든 2바이트 window와 비한글 번역 코드를 제외한 Tier A 후보는
3,087개이며, 그중 원본 빈 글리프 630개와 원본 비어 있지 않은 글리프 194개를 조합해
824개 후보를 정적으로 선정할 수 있습니다. 새 lead 범위 81~88·96과 기존 97~98을 한
화면에서 검사한 진단 ROM도 사용자가 기대 문구와 동일하게 표시됨을 스크린샷으로
확인했습니다. 이 통과 결과를 입력 게이트로 요구하는 생성기로 기존 인트로 45자 코드를
보존한 824자 결정적 후보 매핑을 만들었습니다. CSV 밖 비텍스트 소비 감사 전까지는
production 승인 매핑이 아닙니다.

## 구조·텍스트 분석 결과

- FAT 89, 이름 있는 FNT 파일 53, ARM9 overlay 36, ARM7 overlay 0
- overlay 0~35는 file ID 0~35이고 모두 load address `0x02164A60` 재사용
- 강한 스크립트 2,059개: NUL 경계 2,018개 + 정렬된 직접 포인터 표적 복구 41개
- 보조 문자열 689개: 68개 인접 CP932 문자열 표
- 현재 2,748개 모두 소유 ARM9/overlay 내부에 `u32le` 직접 RAM 포인터 1개 이상
- 강한 참조 분포: 1개 포인터 2,054레코드, 2개 3레코드, 9개 2레코드
- 보조 참조 분포: 1개 545, 2개 92, 3개 33, 4개 12, 5개 1, 6개 4, 7개 2
- 지시자 23종, terminal `%e` 2,059/2,059, unmatched `%` 0
- `%e`는 구조적 끝, `%h`는 주 대화 페이지/대기 경계로 런타임 관측
- `%r` 및 나머지는 의미 미확정이므로 번역기에서 모두 보존
- 포인터 표 바이트가 앞에 붙었던 강한 후보 10개는 첫 지시자 경계로 보정
- 고립 clean CP932 41개, 비 NUL/UI/그래픽 문자열은 아직 모집단 밖
- `data/pack` 49개 raw terminal `%e` 21건은 불투명 리소스 바이너리라 승인하지 않음

`font_lc.bin`은 280,000 bytes, 4,375 glyphs, 16×16 2bpp, 64 bytes/glyph입니다.
Galmuri7 PNG는 8×8 완성형 한글 11,172자와 투명 패딩 28셀을 포함합니다. 전체
완성형은 게임 슬롯보다 많으므로 최종 번역 코퍼스 기반 실사용 글리프 매핑이 필요합니다.

## 화면 정렬형 그래픽 편집 캔버스
