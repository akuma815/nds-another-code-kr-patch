# Another Code NDS 한글화 인수인계

작성: 2026-08-24 KST

이 문서는 `docs/HANDOFF_2026-08-23.md` 이후의 그래픽 런타임 결함 수정과 v13 QA 빌드 상태를 기록한다.

## 현재 중단점

v10 ROM은 melonDS 실기 화면에서 실패했다. 사용자 스크린샷으로 다음 문제가 확인됐다.

- 연도/장소 한글이 흐리고 일부 획이 회색 블록처럼 표시됨
- `앗`, `왜` 주변에 원문 또는 잘못된 팔레트 잔재가 붙음
- 오프닝의 별도 문구와 오프닝용 중복 타이틀 로고가 미번역
- `대화`는 더 크게 중앙 정렬할 여지가 있음
- `조사`, 비활성 `조사`, `뒤로` 아이콘 변형이 추가로 필요함

v10 실패 증거는 `qa/runtime/full-translation-graphics-v10-001/result.json`에 반영했다.

수정판 v13은 정적 빌드와 재현성 검증을 통과했지만 melonDS 1.1 런타임 화면에서 실패했다. 연도/장소와 여러 오프닝 문구의 한글 획이 끊기거나 사라졌으며 정적 indexed preview와 실제 출력이 일치하지 않았다. 따라서 v13은 배포 또는 후속 번역의 기준 ROM으로 사용하지 않는다.

## 원인과 수정

### 런타임 팔레트 역할 불일치

기존 전역 명도 매핑은 한글 안티앨리어싱 픽셀을 리소스 안의 모든 유효 인덱스로 분산했다. NDS 런타임 팔레트에서 인덱스 순서와 밝기 순서는 같지 않기 때문에 관계없는 색 역할이 회색 블록, 흐림, 잔재로 출력됐다.

`workspace/scripts/refine_translated_graphics.py`에 박스별 허용 인덱스 제한을 추가했다. 연도/장소와 `앗`, `왜`는 원문 글자 영역이 실제로 쓰던 팔레트 역할만 사용한다.

### 누락 리소스

다음을 새 캔버스로 추가했다.

- `v05_bg/V5_026`: `애슐리, 빨리 / 숨어!`
- `v05_bg/V5_027`: `엄마…`
- `v05_bg/V5_028`: `완성했다…`
- `v05_bg/V5_029`: `드디어…`
- `v05_bg/V5_030`: `리처드…`
- `v05_bg/title01`, `v05_bg/V5_031`: 오프닝에서 사용하는 중복 타이틀 로고
- `sys_bg/sys_icon`: `대화`, `뒤로`, `조사`, 비활성 `조사`

`sys_bg/title01`, `v05_bg/title01`, `v05_bg/V5_031`의 픽셀 버퍼는 서로 같은 중복 자산임을 확인했다.

### 동일 아틀라스의 여러 아이콘

기존 `build_graphics_pack_qa.py`는 한 리소스당 캔버스 하나만 허용했다. 이를 한 리소스의 여러 크롭을 순서대로 병합한 후 한 번만 재압축하도록 수정했다. v13 보고서에서 `sys_bg/sys_icon`의 네 캔버스가 같은 최종 decoded SHA-256을 가지며 ROM 재읽기 검증도 통과한다.

## Another Code 대사 편집기 v1 (2026-08-24)

Metroid Fusion의 `tools/dialogue_editor` UI 흐름을 참고하되 원본 도구는 수정하지 않고, Another Code 프로젝트 안에 독립적인 Tkinter 편집기를 작성했다.

핵심 동작:

- 기본 입력은 사용자 번역 SSOT `workspace/text/translation/another_code_full_text_v1_ko.csv`이다.
- 원문·`text_id`·raw·포인터 등 보호 열은 UI에서 편집하지 않는다.
- 저장 가능 열은 `translation_text`, `translation_status`, `speaker_names`, `translator_notes`이다.
- `%C(0_xxx)`는 주인공 계열로 분류해 아래쪽 대사창, 다른 `%C(...)`는 위쪽 대사창에 표시한다.
- 한 레코드에 시스템 문구와 여러 화자 페이지가 섞여 있어도 `%h` 페이지별 활성 `%C`를 따라 다시 분류한다.
- `%r`은 같은 창의 줄바꿈, `%h`는 다음 창으로 미리본다. 중첩 괄호가 든 `%w((...))`도 균형 괄호로 파싱한다.
- Galmuri11 Condensed 16×16 승인 아틀라스에서 완성형 한글을 직접 가져오고, 비한글 2바이트 CP932 문자는 원본 `font_lc.bin` 글리프를 사용한다.
- 대화 17자×2줄, 시스템 17자×2줄, 중앙 자막 17자×3줄, auxiliary 16자×1줄 프로필을 제공한다.
- 미확정 소비자는 프로필·최대 글자·줄 수를 사용자가 바꾸고 `text_id`별 sidecar override로 저장할 수 있다.
- 저장 전 원문/번역 제어코드의 정확한 순서와 인수를 비교한다. 기존 파일은 `backups/dialogue_editor`에 백업한다.
- Windows DPI awareness를 켜 4K/배율 화면에서도 창과 픽셀 미리보기의 좌표가 일치하도록 했다.
